Drop the README hero media here.

The top of the root `README.md` references `docs/assets/demo.png` (or `.gif`).
Add one of the following so the hero renders a real demo instead of a broken image:

- `demo.gif` — a short (5–10s) screen capture of the presence orb expanding, a chat
  turn generating an app/widget, and a theme change. Keep it under ~8 MB so it loads
  fast on the GitHub repo page.
- `demo.png` — a single high-resolution screenshot of the v2 Mac host: the draggable
  presence sitting above the real desktop with one generated surface open.

If you ship a `.gif`, update the image path in `README.md` accordingly.

Keep the strict black-and-white, Apple-grade aesthetic in any captured frame.
